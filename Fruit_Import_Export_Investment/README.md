# Fresh Fruit Import & Export — Investment Package

## استيراد الموز السوداني إلى جدة — رأس مال 100,000 ر.س

حزمة استثمارية متكاملة مبنية على صورة بيانات تكلفة شحنة فعلية (`05_Documentation/source_image.jpg`) وتفاصيل مواد التعبئة من العميل. الموز من السودان (سنار/كسلا عبر بورتسودان)، ومواد التعبئة من مصر، والبيع في جدة. كل رقم في الحزمة يأتي من **محرك مالي واحد** هو `01_Investor_Pitch_Deck/engine.js`.

### الأرقام الرئيسية (السيناريو الأساسي)

| المؤشر | القيمة |
|---|---|
| رأس المال | 100,000 ر.س (ثابت؛ الشحن حسب الكاش) |
| رأس المال اللازم للخطة دون قيد | 100,000 ر.س |
| مواد التعبئة لكل شحنة | 107,785 جنيه = 7,699 ر.س |
| مساهمة الشحنة (بعد التكاليف الناقصة) | 22,246 ر.س (الصورة: 34,042) |
| إيرادات السنة 2 / السنة 5 | 1,806,940 / 3,088,313 ر.س |
| صافي ربح 5 سنوات | 1,926,592 ر.س |
| IRR (تخارج دفتري / بمضاعف) | 99.8% / 106.0% |
| الاسترداد النقدي / عبر التوزيعات | الشهر 17 / الشهر 28 |
| دورة التحويل النقدي | 28 يوم (13.0 دورة/سنة) |
| السيناريو المتحفظ | خسارة -912,103 ر.س على 5 سنوات |

### استخدام العرض

- **التنقل:** `←` / `Space` / `PageDown` للشريحة التالية، و`→` / `PageUp` للسابقة، و`Home` / `End`.
- **اختصارات:** `F` ملء الشاشة · `P` لوحة التحكم المالية · `G` فهرس الشرائح · `1` `2` `3` لتبديل السيناريو.
- **لوحة التحكم:** عدّل الأسعار والكميات والشحن والجمارك والتخزين والتلف وشروط الدفع والنمو والمصاريف، وكل الشرائح تتحدث فوراً.
- **الطباعة:** زر ⎙، أو افتح `index.html?print=1` للطباعة. يمكن اختيار السيناريو برابط مثل `?scn=conservative`.
- **الجوال:** يتحول العرض تلقائياً إلى وضع قراءة عمودي.

### إعادة البناء بعد تعديل الافتراضات

عدّل `defaults()` أو `SCENARIOS` في `engine.js`، ثم شغّل:

```bash
cd Fruit_Import_Export_Investment && bash _build/build_all.sh
```

المتطلبات: Node 18+، Python 3 مع openpyxl، LibreOffice (لإعادة حساب Excel في الاختبار)، وPlaywright Chromium (لملفات PDF واختبار العرض).

> هذه الحزمة توقعات مبنية على افتراضات معلنة، وليست عرضاً للأوراق المالية ولا ضماناً لأي عائد.
