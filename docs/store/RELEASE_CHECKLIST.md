## 2. AT-10 — فحص حزم الشبكة

1. جهاز اختبار بشهادة CA لوكيل (مثل mitmproxy) مثبتة كمستخدم. (Android: بناء Development فيه `network_security_config` يثق بشهادات المستخدم، أو جهاز بصلاحيات root.)
2. جلسة كاملة: فتح، وقرب فرع، ومسح رمز الفرع، واسترداد قسيمة، وتصدير تقرير من اللوحة.
3. - [ ] الإحداثيات (`lat`/`lng`) تظهر **فقط** في `verifyPresence` و`scanBranchCode` المتجهة لـ `me-central2-<project>.cloudfunctions.net`.
   - [ ] صفر طلبات لـ `app-measurement.com`، أو `google-analytics.com`، أو `firebase-analytics`، أو `doubleclick`، أو أي SDK إعلانات.
   - [ ] تقرير الشريك وملف CSV: بدون `uid` أو اسم أو إحداثيات، والخانات الصغيرة «أقل من 10».
   - [ ] Firestore Console: ما فيه أي حقل إحداثيات لاعب في `visits` أو `events` أو `users`.
4. - [ ] ساعة في الخلفية: `adb logcat | grep -i -E "location|fused"` خالٍ من طلبات التطبيق. وفي iOS: Settings ▸ Privacy ▸ Location ▸ Football Quest يبين «While Using».

## 3. AT-11 — RTL والمتاجر

**RTL** (لقطة لكل شاشة بالعربية ثم بالإنجليزية، وبأكبر حجم خط للنظام):
- [ ] الإفصاح، والعمر، والمدينة، والـHub، والخريطة (3 مدن)، والملعب، والألبوم، وفتح الحزمة، والاحتمالات، والمحفظة، والقسيمة، والماسح، والإعدادات، و«عن اللعبة»، والتراخيص، وحذف الحساب، وكل الحالات (`NET_OFFLINE`، و`FORCE_UPDATE`، والأذونات).
- [ ] المحاذاة لليمين، والأسهم معكوسة، والأرقام اللاتينية سليمة، والحروف متصلة، وما فيه نص مقصوص.

**المتاجر:**
- [ ] Sign in with Apple بجانب Google.
- [ ] حذف الحساب من داخل التطبيق.
- [ ] نصوص أذونات الموقع والكاميرا بالعربي والإنجليزي (تظهر حسب لغة الجهاز).
- [ ] App Privacy (App Store Connect) وData safety (Play Console) معبّأة حسب `PRIVACY_LABELS.md`.
- [ ] الاحتمالات معلنة داخل التطبيق.
- [ ] الإفصاح ظاهر في البداية و«عن اللعبة» وأول فقرة في الوصف.
- [ ] الاسم والكلمات المفتاحية واللقطات بدون علامات البطولة (`listing.json` يُفحص آليًا، واللقطات يدويًا).

### 3.2 لقطات المتجر

- من البناء الحقيقي فقط، وبالأصول الأصلية (RIGHTS_REGISTER الصفوف 9–13).
- ما فيها كأس، أو شعار، أو علم، أو طقم، أو اسم البطولة، أو صورة ملعب حقيقي.
- مقاسات: iPhone 6.9″، وiPad 13″ (إذا يدعم iPad)، وAndroid هاتف. والعربية أولًا.
