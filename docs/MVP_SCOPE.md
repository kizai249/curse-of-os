# MVP_SCOPE — نطاق النسخة الأولى

**الإصدار:** v1.0 — 21 أكتوبر 2026
**يعتمد على:** `PRODUCT_BRIEF.md` v1.0، و`GAME_RULES.md` v1.0

## 1. القرارات الثابتة

| البند | القرار |
|---|---|
| المنصات | iOS و Android معًا من نفس مشروع Unity |
| الاستكشاف | Hybrid: استكشاف رقمي كامل من أي مكان + مكافآت ميدانية عند القرب |
| الميزانية | Lean: خدمات سحابية مُدارة فقط، وبدون أي خادم ذاتي الإدارة |
| الرسومات | 3D بأسلوب Low-poly / Stylized |
| الفريق | مطوّر واحد (Solo Developer) |
| المحرك والخلفية | Unity LTS + URP، و Firebase: Auth و Firestore و Cloud Functions و Remote Config |

## 2. تعريفات النطاق

| المصطلح | المعنى |
|---|---|
| **Real-time Multiplayer متزامن (خارج النطاق)** | أي محرك أو خدمة تبث حالة اللعب باستمرار بين الأجهزة، أو تزامن فيزياء أو حركة لحظية، مثل Photon و Netcode و Relay. «منتخبنا يجمعنا» ما تخالف هذا لأنها حالة مشتركة مبنية على أحداث منفصلة في Firestore (`PRODUCT_BRIEF.md` ت2) |
| **Background Geofencing (خارج النطاق)** | أي قراءة موقع والتطبيق في الخلفية أو مغلق، بما فيها Region Monitoring في iOS و Geofencing API في Android |
| **التحقق في الواجهة (داخل النطاق)** | قراءة موقع واحدة عند فتح التطبيق، أو العودة له، أو مسح رمز فرع |

| الميزة | الحالة | الإصدار | ملاحظة |

| تجميع المنتخبات: 24 × 4 نسخ، والحزم، والاحتمالات المعلنة، وحماية سوء الحظ، ونقاط المشجع | In-Scope | R1 | — |
| الموقع في الواجهة، ومناطق الملاعب والفروع، ونقاط القرب | In-Scope | R1 | CoreLocation / FusedLocationProvider |
| رمز الفرع اليومي، وتسجيل الحضور، والزيارة المحققة | In-Scope | R1 | — |

| لوحة الشركاء (ويب): الحملات، والفروع، والمناطق، وشاشة الفرع، ووضع الموظف، والتقارير المجمعة | In-Scope | R1 | Firebase Hosting |

| Background Geofencing | **Out-of-Scope** | — | خصوصية وبطارية |

## 6. معايير «جاهز للرفع» لكل إصدار

- كل اختبارات `ACCEPTANCE_TESTS.md` الخاصة بميزات الإصدار ناجحة.
- كل ميزة من إصدار لاحق مخفية بمفتاح Remote Config قيمته `false`.
- إفصاح «غير رسمي» ظاهر في شاشة البداية و«عن اللعبة» ووصف المتجر.
- صفر أصول من فئة «يحتاج ترخيص» في البناء (`RIGHTS_REGISTER.md`).
