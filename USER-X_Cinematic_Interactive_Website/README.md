# USER-X · موقع سينمائي تفاعلي مع «نقطة»

الموقع يدخّل الزائر لعالم يوزر إكس كأنه داخل لعبة:
- **المقدمة:** فيلم افتتاحي 12 ثانية يبدأ أول ما تفتح الموقع بدون أي ضغطة: نبضة بكسل، ثم الأسهم الأربعة تنضرب ونفق X، ثم العوالم الأربعة بقطعات سريعة وموزاييك، ثم «ما تتفرّج. إنت اللعبة.»، ثم الرمز يتجمّع والشعار. يدخلك الموقع لحاله في الآخر. الصوت يشتغل مع أول لمسة، لأن المتصفحات تمنع تشغيل الصوت تلقائياً.
- **12 مشهد:** متصلة ببعض.
- **«نقطة»:** شخصية بكسلية تعيش في الموقع. يمشي ويروح ويجي، ويروح عند اللعبة اللي توقف عليها ويعلّق عليها، ويعطيك نصيحة إذا وقفت في قسم، ويتكلم بالصوت بعد أول لمسة، ويجاوب على أسئلتك من معلومات يوزر إكس المؤكدة بس. اضغطه وهو يتكلم ويسكت.
- **التحويل:** كل طرق الحجز والطلب تفتح واتساب برسالة جاهزة على الرقم ‎+966 56 595 2065، والموقع في جدة.

## التشغيل
```bash
npm install
cp .env.example .env        # اختياري: مفاتيح الذكاء الاصطناعي والصوت
npm start                   # http://localhost:8080
```
- **بدون مفاتيح:** الموقع يشتغل كامل، و«نقطة» يجاوب من قاعدة المعرفة على المتصفح (وضع المعلومات المؤكدة).
- **مع `ANTHROPIC_API_KEY`:** «نقطة» يصير محادثاً ذكياً. المفتاح يبقى على السيرفر بس.

## ليش هالتقنية؟ (قرار الـ stack)
- **الواجهة:** HTML وCSS وJavaScript بدون framework وبدون build.
  - **السبب:** الموقع الموجود مبني كذا، وفيه نظام حركة بكسلي (`steps()`) واختبارات شغّالة. الانتقال لـ React أو Next.js ما يضيف تجربة أحسن، ويضيف build وصيانة.
  - **السرعة:** على جوال بشبكة 4G بطيئة، المحتوى الرئيسي يظهر في 1.3 ثانية.
- **Three.js و GSAP:** ما استخدمتهم عمداً.
  - **السبب:** هوية العلامة بكسل حاد، والحركة المطلوبة (خطوات، تجمّع، ركض بكسلي) تنعمل بـ CSS وSVG بدون 600KB من المكتبات.
  - **متى يتغيّر القرار:** إذا صار عندكم مجسّم 3D لـ«نقطة» (GLB). هيكل الـ Avatar قابل للتبديل، والتفاصيل في `public/assets/avatar/nuqta.js`.
- **السيرفر:** Node.js بدون framework، وفيه اعتمادية وحدة: `@anthropic-ai/sdk`. وظيفته:
  - يقدّم الملفات.
  - يحمي المفاتيح.
  - يحدّ من الطلبات.
  - يضغط الملفات النصية.
- **الذكاء الاصطناعي:** Claude Opus 5.5 عبر Messages API. قاعدة المعرفة كاملة داخل system prompt مع prompt caching، بدون قاعدة بيانات متجهات.
  - **السبب:** المعرفة كلها حوالي 19 ألف حرف، فالنموذج يقرأها كاملة بدقة أعلى من أي بحث تقريبي، والـ cache يخلّي تكرارها رخيص.
  - **متى نحتاج vector DB:** إذا صارت المعرفة مئات الصفحات.

## الهيكل
```
public/                     الموقع (يتقدّم كما هو)
  index.html                12 مشهد + «نقطة» + نموذج الطلب
  intro/                    فيلم المقدمة (cinema.js + cinema.css) وموسيقاه المولّدة
  styles.css · script.js    نظام الهوية والحركة والمشاهد (من موقع يوزر إكس الأصلي)
  nuqta/nuqta.js            نقطة: الحركة والركض، المحادثة، الصوت، الأسئلة
  nuqta/brain.js            عقل نقطة بدون ذكاء اصطناعي (يقرأ knowledge/*.json)
  nuqta/site.css            أنماط الأقسام الجديدة ونقطة
  knowledge/*.json          قاعدة المعرفة (10 ملفات، 28 إجابة، كل وحدة بمصدرها وحالتها)
  assets/                   الخطوط والشعارات والشخصية وصور العوالم
server/
  server.js                 السيرفر و /api/health · /api/nuqta · /api/tts
  lib/nuqta-ai.js           system prompt لنقطة + طلب Claude
  lib/kb.js                 تحميل المعرفة والبحث فيها
  lib/guards.js             حد الطلبات، سقف يومي، فحص المدخلات
  lib/tts.js                صوت طبيعي اختياري (ElevenLabs)
tests/                      اختبارات السيرفر والمتصفح
docs/                       النشر، المفاتيح، خريطة المحتوى، التقارير
```
