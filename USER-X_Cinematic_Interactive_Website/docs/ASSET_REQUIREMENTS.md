# المواد اللي تحتاج إنتاج

| المادة | الحالة الآن | المطلوب | وين تنحط |
|---|---|---|---|
| فيديو لعب حقيقي لكل تجربة | **غير موجود.** صفحات الألعاب فيها صور العوالم ومؤثرات CSS | 15–30 ثانية لكل لعبة، 1920×1080 و720×1280 للجوال، بدون صوت مزعج، مع صورة poster | `public/assets/video/` + حقل جديد في `GAMES` في `script.js` |
| فيلم المقدمة | مستخدم: مولّد بالكود في المتصفح (`public/intro/cinema.js`) من عناصر الهوية وصور العوالم، وموسيقاه مولّدة بـ Web Audio (أصلية). ما فيه لقطات لعب | إذا صوّرتوا لقطات لعب حقيقية، تنحط كقطعات في المشهد الثالث بدل صور العوالم | `PANELS` في `public/intro/cinema.js` |
| صوت نقطة | صوت المتصفح، أو ElevenLabs إذا انضاف المفتاح | صوت مخصّص بلهجة سعودية (استنساخ صوت ممثل بعقد وموافقة مكتوبة) | `ELEVENLABS_VOICE_ID` |
| موسيقى وأصوات | مولّدة حيّاً بـ Web Audio (أصلية، بدون حقوق) | اختياري: ملفات مرخّصة للمقدمة والأجواء | `USERSX_CONFIG.audio` في `index.html` |
| مجسّم 3D لنقطة | غير موجود. الشخصية بكسل SVG | ‏GLB بتحريك (idle، ركض، قفز، رقص، تلويح). المواصفات في `users-x-web/docs/AVATAR_SPEC.md` | تبديل الـ renderer في `Avatar` |
| صورة مشاركة og:image | غير موجودة | 1200×630 من شريحة «ما تتفرّج. إنت اللعبة.» | `public/assets/og.jpg` + وسم meta |
| شهادات وشعارات عملاء | غير موجودة، وما راح تنخترع | بعد أول فعاليات، مع إذن العميل | قسم جديد في «للجهات» |

**قاعدة:** أي لقطات مولّدة بالذكاء الاصطناعي أو بالكود لازم تنكتب عليها إنها توضيحية، ولا تنعرض كأنها لعب حقيقي.
