# إعداد الذكاء الاصطناعي والصوت

كل المفاتيح في `.env` على السيرفر بس. `.env` داخل `.gitignore`، وفيه اختبار يتأكد إن ما فيه مفتاح في ملفات `public/`.

| المتغيّر | لازم؟ | وظيفته |
|---|---|---|
| `ANTHROPIC_API_KEY` | لا. بدونه نقطة يشتغل من المعلومات المؤكدة | مفتاح Claude من console.anthropic.com |
| `NUQTA_MODEL` | لا (`claude-opus-5-5`) | النموذج |
| `NUQTA_RATE_PER_MINUTE` | لا (8) | حد الطلبات لكل زائر بالدقيقة (مع دفعة 4) |
| `NUQTA_DAILY_REQUEST_CAP` | لا (2000) | سقف يومي لكل السيرفر. بعده يتحول نقطة للوضع الاحتياطي |
| `ELEVENLABS_API_KEY` + `ELEVENLABS_VOICE_ID` | لا | صوت طبيعي لنقطة. بدونهم يستخدم صوت المتصفح |
| `TRUST_PROXY=1` | فقط خلف proxy موثوق | يقرأ IP الزائر من `X-Forwarded-For` لحد الطلبات |
| `PORT` | لا (8080) | |

## التكلفة: تقدير وليس فاتورة
**Claude Opus 5.5:** ‎$4 لكل مليون توكن داخل، و‎$20 لكل مليون خارج. قراءة الـ cache ‎$0.20 للمليون.
- الـ system prompt حوالي 19 ألف حرف، تقريباً 7–9 آلاف توكن مع العربي. بعد أول رسالة يُقرأ من الـ cache، وهذا يقارب ‎$0.002 للرسالة.
- الرد مع التفكير بمجهود `low` حوالي 200–500 توكن خارج، يعني ‎$0.004–0.01.
- **التقدير:** حوالي سنت إلى سنتين لكل رسالة. السقف الافتراضي 2000 رسالة باليوم يعني أقصى تقريباً ‎$20–40 باليوم.

قيسوا من لوحة Anthropic بعد أسبوع، وعدّلوا السقف على الاستخدام الحقيقي.

**ElevenLabs:** يُحسب بالأحرف حسب باقتكم. رد نقطة غالباً 100–300 حرف، والحد الأقصى في السيرفر 400 حرف للطلب و6 طلبات بالدقيقة لكل زائر. راجعوا الأسعار الحالية لباقتكم قبل التفعيل.

## ضبط الطلب (`server/lib/nuqta-ai.js`)
- `client.beta.messages.create` مع `fallbacks: "default"` (بيتا `server-side-fallback-2026-07-01`): إذا رفض النموذج لأسباب أمان، الـ API يعيد المحاولة على نموذج بديل داخل نفس الطلب.
- `output_config: { effort: "low", format: json_schema }`: رد قصير ومنظّم. التفكير دائماً شغّال في Opus 5.5، والمجهود هو اللي يتحكم بعمقه.
- `cache_control: ephemeral` على الـ system prompt.
- مهلة 30 ثانية، ومحاولة إعادة وحدة.

## الأمان
- **المفاتيح:** ما تطلع للمتصفح أبداً. `/api/health` يرجّع بس إذا الخدمات مفعّلة أو لا.
- **مصدر الطلب:** POST مقبول من نفس الموقع بس، والطلبات من موقع ثاني ترجع 403.
- **حجم الطلب:** الحد 16KB للمحادثة و4KB للصوت، وأي شي أكبر يرجع 413.
- **المدخلات:** 600 حرف للرسالة، وآخر 12 رسالة، وتبادل أدوار صارم. المحادثة ما تقدر تبدأ برسالة «assistant» ملفّقة.
- **ترويسات الأمان:** CSP و`nosniff` وReferrer-Policy، و`frame-ancestors 'none'`.
- **مسارات الملفات:** محمية من `../`.

## الخصوصية
- **المحادثة:** تمر على السيرفر لـ Anthropic، وما تنحفظ على السيرفر. السجل فيه عدد التوكنات بس، بدون نص.
- **نموذج الحجز:** ما يرسل شي للسيرفر أصلاً. يبني رسالة واتساب في متصفح الزائر، والزائر هو اللي يرسلها.
- **localStorage:** يحفظ إعدادات العرض بس: الصوت، والحركات، ورؤية المقدمة. ما فيه تتبّع ولا cookies.
- **قبل الإطلاق:** أضيفوا سياسة خصوصية رسمية تذكر Anthropic (و ElevenLabs إذا فعّلتوه) كمعالجين للبيانات، وراجعوا متطلبات نظام حماية البيانات الشخصية في المملكة.

## حدود الصوت
- **صوت المتصفح:** يختلف حسب الجهاز. أغلب الأجهزة فيها صوت عربي فصيح، مو سعودي، والجودة متوسطة.
- **الصوت الطبيعي باللهجة:** يحتاج صوت مخصّص في ElevenLabs (أو مزوّد آخر) ويُختبر مع الفريق.
- **الكلام بالصوت:** يشتغل بس في المتصفحات اللي تدعم Web Speech API، وفي Chrome يرسل الصوت لخوادم Google.
