# تقرير الأداء

القياس محلي بـ Chromium (Playwright). هالأرقام من المختبر، مو من زوار حقيقيين، فقيسوا بعد النشر بـ PageSpeed Insights.

| الحالة | ظهور المحتوى الرئيسي (LCP) | ثبات الصفحة (CLS) | DOMContentLoaded | ذاكرة JS |
|---|---|---|---|---|
| حاسب 1366×860 | 0.24 ث | 0 | 0.29 ث | 9.5MB |
| جوال 390×844، شبكة 4G محاكاة (1.6Mbps، 150ms) والمعالج أبطأ ×4 | **1.31 ث** | 0.03 | 3.2 ث | 9.5MB |

المعيار الجيد: LCP أقل من 2.5 ثانية، وCLS أقل من 0.1. الحالتين ضمن المعيار.

## وزن الصفحة (قبل الضغط، أول تحميل)
| النوع | الحجم |
|---|---|
| الخطوط (woff2، مضغوطة أصلاً، مع `unicode-range`) | 344KB |
| الصور (صور العوالم + الستيكر) | 220KB |
| JavaScript (script.js + نقطة + الشعار + الشخصية) | 119KB، **حوالي 35KB بعد gzip** |
| CSS | 77KB، حوالي 15KB بعد gzip |
| HTML | 51KB، حوالي 12KB بعد gzip |
| قاعدة المعرفة (10 ملفات JSON، تنحمّل بعد الصفحة) | 30KB |
| **المجموع** | حوالي 840KB قبل الضغط، وحوالي 650KB فعلياً |

**فيلم المقدمة ما فيه ملف فيديو.** يترسم حيّاً على canvas من الرمز وصور العوالم الموجودة أصلاً (حوالي 20KB كود قبل الضغط)، فالموقع ما ينزّل أي ميغابايتات فيديو. التريلر القديم انحذف، والاختبار يتأكد إن ما فيه أي طلب فيديو.

## اللي انعمل للأداء
- **بدون مكتبات:** لا Three.js ولا GSAP ولا React. الحركة بـ CSS `steps()` وSVG.
- **المقدمة:** canvas واحد، والرسم يتوقف أول ما ينتهي الفيلم أو ينضغط «تخطَّ». مع تقليل الحركة يطلع الشعار ثابت 2.4 ثانية بس.
- **السيرفر:** ضغط gzip للملفات النصية، وcache لمدة 30 يوم للخطوط والصور والفيديو، و5 دقائق للـ HTML وJS.
- **حركات نقطة:** مؤقتات خفيفة كل 62ms وقت الركض بس، وتوقف إذا الصفحة مخفية أو المحادثة مفتوحة أو فيه نافذة. مستمع الماوس مشترك ومحدود بـ requestAnimationFrame.
- **الأرضية والنجوم:** تتوقف خارج الشاشة، ومع تقليل الحركة.
- **الذكاء الاصطناعي:** system prompt ثابت البايتات عشان الـ prompt cache، ومجهود `low` لسرعة الرد.

## تحسينات ممكنة لاحقاً
- **الصور:** تحويلها لـ WebP أو AVIF، بتوفير تقريبي 40%.
- **خطوط العوالم الثلاثة:** Blaka وChanga وMarhey ممكن تنحمّل بس لما يفتح الزائر عالم اللعبة.
- **CDN:** تقديم الملفات من CDN (Cloudflare مثلاً) قريب من السعودية.
