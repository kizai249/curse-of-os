# USER-X · بطاقة خالد حميدة الرقمية

بطاقة عمل رقمية تفاعلية تنفتح من رمز QR. ما هي صفحة تعريف عادية، هي «بطاقة لاعب»:

1. **الدخول (٥ ثواني بالكثير):** رمز يوزر إكس يتجمّع بكسل بكسل، ومعه «لاعب جديد دخل اللعبة.» وزر «اضغط للبدء». يقدر الزائر يتخطاها فوراً، ولو ما سوى شي تكمل لحالها.
2. **البطاقة:** بطاقة ثلاثية الأبعاد:
   - تميل مع الماوس أو مع سحب الإصبع، ولمعتها تلحق حركتك، وإطارها نيون يدور.
   - عليها الاسم بالعربي والإنجليزي، والمسمى، والمدينة، ونبذة قصيرة، و«إحصائيات اللاعب».
   - تنقلب، وعلى ظهرها «نقطة» ونبذة عن يوزر إكس.
3. **التحدي، «امسك نقطة!» (١٢ ثانية):**
   - المس نقطة قبل ما يختفي. كل ما كنت أسرع، تاخذ نقاط أكثر.
   - من الثانية الخامسة، أحياناً ينط لمكان ثاني.
   - المربع الأحمر يخصم ١٥ نقطة.
   - المربع الماجنتا مكافأة (+٢٥).
   - إذا مسكته ٣ مرات ورا بعض، كل مرة بعدها تاخذ +٥ زيادة.
   - فيه عد تنازلي، ونقاط ووقت على الشاشة، ونقطة يعلّق عليك.
4. **النتيجة:** أربع مستويات بالعربي والإنجليزي، تختلف فيها ردة فعل نقطة. لما توصل للنتيجة العالية تفتح **البطاقة الذهبية**. وتقدر تشارك نتيجتك.
5. **الجائزة، التواصل:**
   - احفظ جهة الاتصال (ملف ‎.vcf حقيقي).
   - واتساب، واتصال، ومشاركة البطاقة، ورمز QR.
   - الإيميل ولينكدإن يطلعون لما تعبّيهم.
6. **السر:** المس شعار البطاقة ٥ مرات بسرعة، أو اضغط ↑↑↓↓ في الكيبورد، ويفتح لك «المستوى السري»: نقطة يرقص ورسالة مخفية.

**عربي / English:** زر واحد يبدّل اللغة والاتجاه (RTL / LTR). الافتراضي عربي، والرابط مع `?lang=en` يفتح بالإنجليزي، فتقدر تطبع QR ثاني للضيوف الأجانب.

**الصوت:** مؤثرات أصلية تتولّد في المتصفح، بدون أي ملف صوتي. **مقفل افتراضياً** وما يشتغل إلا بضغطة على زر الصوت. ومستوى الصوت من الإعدادات.

**تقليل الحركة:** يتبع إعداد الجهاز (prefers-reduced-motion). وفيه خيار «قلّل الحركة» في الإعدادات.

## التشغيل محلياً
```bash
npm install          # مرة وحدة (أدوات الاختبار وQR فقط — الموقع نفسه ما يحتاج تثبيت)
npm start            # http://localhost:8090
npm test             # يبني ملف جهة الاتصال + 6 اختبارات وحدة + 23 اختبار متصفح
```

## التعديل: كل شي في ملف واحد
**`config/card.config.js`** فيه كل شي:
- الاسم والمسمى والنبذة.
- الأرقام والإيميل ولينكدإن والموقع.
- رابط البطاقة.
- اللغة الافتراضية.
- إعدادات اللعبة ومستويات النتائج.
- التحليلات.

**قاعدة المعلومات:** أي خانة فاضية (`''`) معناها «مو مؤكد». زرّها ينخفي، وملف جهة الاتصال ما يحطها. ما فيه أي معلومة مخترعة.

| الخانة | الحالة الحين |
|---|---|
| `companyPhone` / `companyWhatsapp` | **+966 56 595 2065**: رقم يوزر إكس الموثّق في ملفات المشروع (إعدادات الموقع) |
| `personalPhone` / `personalWhatsapp` | فاضي. **ما لقيت رقم خالد الشخصي في الملفات.** إذا تعبّى، يصير زر الواتساب والاتصال على رقمه بدل رقم الشركة |
| `email` | فاضي. الزر مخفي لين ينضاف |
| `linkedin` | فاضي. الزر مخفي لين ينضاف |
| `website` | فاضي. رابط الموقع على ظهر البطاقة مخفي |
| `cardUrl` | فاضي. **حطه بعد النشر** (شوف تحت) |

بعد أي تعديل على الملف:
```bash
npm run build        # يعيد كتابة contact/khalid-hamida-userx.vcf من الإعدادات
```

## النشر ورمز QR (الخطوات بالترتيب)
1. **انشر المجلد كما هو.** الموقع ثابت وما يحتاج سيرفر ولا بناء، فيشتغل على Netlify أو Vercel أو Cloudflare Pages أو GitHub Pages أو أي استضافة HTTPS. التفاصيل في [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md).
2. **حط الرابط النهائي في `cardUrl`**، مثلاً `'https://card.user-x.sa/khalid/'`.
3. **أعد البناء وانشر مرة ثانية:**
   ```bash
   npm run build
   ```
   عشان ملف جهة الاتصال يحمل رابط البطاقة.
4. **ولّد رمز QR:**
   ```bash
   npm run qr
   ```
   أو حط رابط معيّن، مثلاً عشان تعرف كم واحد دخل من البطاقة المطبوعة:
   ```bash
   npm run qr -- "https://card.user-x.sa/khalid/?src=qr"
   ```
   النتيجة في مجلد `qr/`:
   - `userx-khalid-hamida-qr.svg`: ملف فيكتور للطباعة بأي حجم. **هذا اللي تعطيه المطبعة.**
   - `userx-khalid-hamida-qr.png`: ‏2048 بكسل، للشاشات والعروض.
   - `userx-khalid-hamida-qr-print.png`: ‏4096 بكسل، للمطابع اللي تطلب صورة.
   - `destination.txt`: الرابط بالضبط.
5. **امسح الرمز بجوالين** (آيفون وأندرويد) قبل الطباعة.

**حماية من رابط ميت:** الأداة **ترفض** أي رابط محلي (localhost) أو رابط معاينة أو رابط مو HTTPS، فما ينطبع رمز يودّي لصفحة ما تفتح. ونافذة QR داخل البطاقة تعطيك تحذير إذا كانت مفتوحة من رابط معاينة.

**نصائح الطباعة:**
- لا تصغّر الرمز تحت **2 سم**.
- خلّ حوله إطار أبيض. الملف فيه هامش جاهز.
- اطبعه أسود على أبيض.
- مستوى تصحيح الأخطاء **Q**، يعني الرمز يتحمّل خدش بسيط.

**تغيير الوجهة بعد الطباعة:** لو طبعت الرمز على رابط مثل `https://card.user-x.sa/khalid/`، تقدر تنقل البطاقة لاحقاً بتحويل (redirect) من هذا الرابط، بدون ما تعيد الطباعة.

## الهيكل
```
index.html              الصفحة (4 مشاهد + نافذة QR + المستوى السري)
config/card.config.js   كل البيانات القابلة للتعديل
src/js/app.js           المشاهد، والبطاقة، والتواصل، والمشاركة، وQR، والسر، والتحليلات
src/js/game.js          لعبة «امسك نقطة!»
src/js/audio.js         المؤثرات الصوتية (Web Audio، أصلية)
src/js/fx.js            خلفية البكسلات وانفجارات النقاط
src/js/i18n.js          نصوص الواجهة بالعربي والإنجليزي
src/js/vcard.js         مولّد ملف جهة الاتصال (يستخدمه المتصفح وأداة البناء)
src/styles/card.css     التصميم والحركة
assets/brand/           رمز يوزر إكس وشعارها وشخصية «نقطة» (من هوية يوزر إكس)
assets/fonts/           Kufam، وIBM Plex Sans Arabic، وHandjet، وSpace Mono (رخصة OFL)
assets/vendor/          qrcode-generator (رخصة MIT)
contact/                ملف ‎.vcf الجاهز
qr/                     ملفات QR بعد ما تشغّل npm run qr
tools/                  سيرفر محلي، وبناء ملف جهة الاتصال، ومولّد QR
tests/                  اختبارات الوحدة والمتصفح، وجولة لقطات الشاشة
docs/                   النشر، وتقرير الاختبار، وقائمة الملفات
```
