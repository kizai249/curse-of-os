# USER-X — حزمة تطوير 10 ألعاب إقصاء أصلية

**الحالة:** تصميم مفاهيمي جاهز للنماذج الأولية (MVP). القواعد اختُبرت بمحاكاة حاسوبية فقط، ولم تُختبر مع لاعبين بعد. الأسعار تقديرية ما لم يُذكر مرجع موثّق.

## الملفات

| الملف | المحتوى |
|---|---|
| `USER-X_10_Games_GDD_Arabic.pdf / .docx` | وثيقة التصميم: فصل لكل لعبة (الأقسام أ–ع) + بطاقة الاختيار + الهوية البصرية |
| `USER-X_10_Games_Comparison.xlsx` | مقارنة الألعاب العشر، التقييم من 100، الترتيب، والأفضل في كل هدف |

## ما هو حقيقي وما هو مفهوم (3D)

| المخرج | النوع |
|---|---|
| `model/*.glb`, `*.obj` | **نماذج ثلاثية الأبعاد حقيقية** مولّدة بالكود بالأبعاد المذكورة في وثيقة التصميم (blockout بأشكال أولية) |
| `fabrication_stl/*.stl` | **قطع حقيقية بالمليمتر** كمرجع للورشة، وليست رسومات تنفيذية معتمدة |
| `renders/*.png` | **صور مُصيّرة فعليًا** من ملفات GLB (three.js) بستة مناظر: أمامي، جانبي، علوي، منظور، منظور اللاعب، وتفصيل مكوّن |
| `layout/*.svg/png` | مخطط علوي بالمقياس (شبكة 1 م) |
| `blender/*.py` | سكربت Blender يعيد بناء المشهد: **مولّد وتم التحقق من صياغته، لكنه لم يُشغَّل داخل Blender** |

## إعادة البناء

الملفات كلها تُولَّد من `_build/` (مصدر واحد للبيانات: `common.py`، `games_a.py`، `games_b.py`):

```bash
cd _build && python3 sim.py && python3 models3d.py && python3 xlsx_finance.py && python3 xlsx_others.py && python3 build_docs.py && python3 build_pptx.py
```

التصيير يحتاج three.js محليًا (`render/render.mjs`، و`render/svg2png.mjs` لتحويل المخططات). الخطوط المستخدمة Cairo وTajawal (Google Fonts، OFL).

## الهوية

لم نجد ملفات شعار أو ألوان USER-X في المشروع، فاستخدمنا هوية مؤقتة (أسود #0B0B0F، إشارة #FF4D00، رملي #C9A66B). تُستبدل بالهوية الرسمية بتعديل `common.py` ثم إعادة البناء.
