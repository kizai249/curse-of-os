# عينات العقود (Contract Samples)

أشكال ردود الخادم ومستندات المحتوى كما يقرأها عميل Unity. **القيم توضيحية للشكل فقط** (مثل DATA_CONTRACTS)،
وما هي بيانات حقيقية: مثلًا `content.schedule.json` مو جدول البطولة.

- C# (`tools/core-tests`): يحلل كل عينة.
- TypeScript (Emulator): يتأكد إن الرد الفعلي له نفس المسارات والأنواع.
