# USERS-X · تجربة HTML تفاعلية سينمائية

تجربة ويب تعرّف بـ«يوزرز إكس» عبر قصة من 9 مشاهد: مقدمة، العالم، الرمز التفاعلي، الدليل «نقطة»، مين إحنا، عالم التجارب، ليش إحنا، بوابة التواصل، والخاتمة «اللعبة بدأت. قرارك.».

مبنية بـ HTML وCSS وJavaScript فقط، بدون مكتبات وقت التشغيل وبدون خطوة build.

## التشغيل
```bash
cd users-x-web
python3 -m http.server 8080      # أو أي سيرفر ملفات ثابتة
# افتح http://localhost:8080
```
تقدر تفتح `index.html` مباشرة من الملف، لكن السيرفر أفضل لأن الخطوط وملفات الصوت الاختيارية تنحمّل منه.

## الهيكل
```
index.html                 الصفحة + إعدادات USERSX_CONFIG (البريد/الحسابات/الصوت)
styles.css                 التوكنز، نظام الحركة، كل المشاهد، الجوال، تقليل الحركة
script.js                  تنسيق المشاهد (كل وحدة معزولة بـ safeStart)
assets/logo/symbol.js      شبكة رمز D-PAD X الأصلية 15×15 (مأخوذة بالبكسل من ملف الهوية ص7)
assets/logo/*.svg|png      الرمز، الشعار العربي/اللاتيني، الستيكر (من ملف الهوية الرسمي)
assets/avatar/nuqta.js     شخصية «نقطة» كبيانات بكسل + مُخرج SVG
assets/avatar/nuqta.svg    نسخة ثابتة (تُولّد من tools/export-assets.mjs)
assets/games/*-world.jpg   عوالم الألعاب الأربعة (من ملف الهوية ص13–17)
assets/fonts/              Kufam · Handjet · IBM Plex Sans Arabic · Space Mono + خطوط العوالم Blaka · Changa · Marhey (SIL OFL 1.1)
assets/audio/README.md     الصوت مُركّب حيّاً — الملفات اختيارية
docs/AVATAR_SPEC.md        مواصفات الشخصية ومتطلبات نسخة 3D
tests/e2e.cjs              اختبارات قبول تنفيذية في متصفح حقيقي
tools/export-assets.mjs    يعيد توليد SVG الثابتة من المصادر
```

## الاعتماديات الخارجية
- **وقت التشغيل:** لا شيء. لا CDN ولا Google Fonts ولا Three.js. اخترت CSS/SVG لأن الهوية بكسل حاد، وقرار عدم استخدام Three.js مقصود. الخطوط مستضافة محلياً.
- **الاختبارات فقط:** Playwright + Chromium.

## نظام الهوية المطبّق
- الألوان الأصلية بدون تعديل: Bone `#F4F4F1` · Void `#0B0B0F` · Cyan `#00DEE6` · Magenta `#F54BF7`.
- الخطوط: Kufam للعناوين، وPlex للنصوص، وHandjet للأرقام، وSpace Mono للتسميات اللاتينية.
- الرمز يُرسم من شبكته الأصلية بدون أي تدوير. في التفاعل تنفصل الأذرع بكسل ونص وترجع لنفس المقاس بالضبط، والاختبار يتحقق من هذا الرجوع.
- الحركة بخطوات (`steps()`): البكسل يتجمّع ويتفكّك بدل ما يظهر ويختفي، وما فيه توهج ولا كروم.
- قاعدة «العربي أولاً واللاتيني تحته» مطبّقة في الشعار وفي كل العناوين.

## عوالم الألعاب
كل لعبة «عالم بحاله» (ملف الهوية ص13–20): البطاقة وصفحة اللعبة تلبس خط اللعبة وألوانها وصورتها، والإطار (الشعار، التنقل، الأزرار العلوية) يبقى USERS-X.

|---|---|---|---|
| لعنة أوس | Blaka | `#07060A` `#E9DFCF` `#A3121F` `#B08D57` | `horror` — ضوء يتبع المؤشر في عتمة الشمعة |
| غرفة الاختيار | Changa ExtraBold | `#EDECE8` `#111114` `#E5283A` `#0FB5A4` | `choice` — ضوء البابين وعدّاد ٣٠ ثانية |
| آخر من يصمد | Changa ExtraBold | `#0D0B08` `#F2EDE4` `#FFC400` `#FF5A1F` | `survival` — ١٦ دائرة تطلع واحدة واحدة مع 00:59 |
| مشوار آسيا (Football Quest) | Marhey | `#04351F` `#FFFFFF` `#F5C542` `#2BD67B` | `stadium` — قصاصات احتفال، مسار المباريات، العملات |

## إضافة لعبة جديدة
أضف عنصر إلى `GAMES` في `script.js`:
```js
{ id, title, titleEn, genre, tags: ['horror'|'teams'|'group'|'sports'], effect: 'horror'|'choice'|'survival'|'stadium'|'mystery',
  art: 'assets/games/x-world.jpg', world: { bg, fg, a1, a2, font }, mood, status, statusKind: 'live'|'template'|'soon',
  tagline, premise, gameplay, stats: [[value, label]], warning?, cta, caption, line }
```
كل مؤثر معزول (`EFFECTS[name].mount(stage, game)` يرجّع دالة تنظيف)، ولو فشل تظهر صورة العالم ثابتة. قالب `mystery` جاهز لأي لعبة تحقيق جاية.

## العناصر المؤقتة (Placeholders) اللي تحتاج استبدال
| العنصر | المكان | الحالة الحالية |
|---|---|---|
| بريد الاستقبال الرسمي | `USERSX_CONFIG.contact.email` في `index.html` | فاضي. النموذج يجهّز نص الرسالة مع زر نسخ، ويقول بوضوح إنها «ما انرسلت». ما فيه mailto. |
| حسابات التواصل الاجتماعي | `USERSX_CONFIG.social` | فاضية، ويظهر مكانها نص مؤقت واضح |
| حالات الألعاب | `GAMES[].status` | من النسخة الجديدة لملف الهوية: لعنة أوس «مباشر · فصل ١ من ٣»، غرفة الاختيار «قالب»، آخر من يصمد «تحدي الأسبوع · المرحلة ٣ من ٥». مشوار آسيا «قريباً» من النسخة الأولى — الجديدة ما ذكرت حالته |
| اسم وشكل الدليل «نقطة» | `assets/avatar/` | مقترح أصلي ينتظر اعتماد الفريق |
| الصوت | `USERSX_CONFIG.audio` | مُركّب حيّاً بشكل أصلي، والملفات المسجّلة اختيارية |
| النطاق users-x.sa وأرقام الكرت الشخصي | — | **ما استخدمتها**، لأنها في ملف الهوية مجرد نماذج توضيحية |

## الاختبارات
```bash
node users-x-web/tests/e2e.cjs [مجلد-للقطات-اختياري]
```
31 اختبار تنفيذي في Chromium حقيقي، وكلها ناجحة (31/31) بعد آخر تعديل. تغطي:

- **المقدمة:** المراحل توصل للدعوة، وزر «ادخل التجربة» يشتغل، والتخطي يشتغل، وزر X يشتغل. إعادة التحميل في نفس الجلسة أو الرابط المباشر يتخطاها. لو ملف صوت ناقص يشتغل الصوت المُركّب بدون أخطاء. الصوت ما يبدأ قبل ما يتفاعل الزائر.
- **الرمز:** نقرة وحدة تكشف، و6 نقرات سريعة تعطي كشف واحد بس. Esc يرجّعه. الكيبورد والأسهم تتنقل بين الأذرع، والذراع ينقلك للقسم. المقاسات ترجع لأصلها.
- **الدليل:** يرسم ويسلّم ويتفاعل مع النقر ويلوّح وعيونه تتبع المؤشر. بطاقة الشخصية تفتح. الدليل المصغّر ما يظهر مع الدليل الأساسي بنفس الوقت، ويتسكّر، ويرجع من الإعدادات.
- **مين إحنا:** كل الفصول تنكشف.
- **التجارب:** كل بطاقة تفتح لعبتها مع المؤثر الصحيح. الرجوع يمسح المؤثر ويرجّع مكان التمرير والتركيز. التالي والسابق ما تتراكم فيها المؤثرات. Esc يسكّر. الفلاتر تشتغل. كل بطاقة وصفحة تلبس ألوان عالمها وخطه. لو تعطّل مؤثر يظهر بديل ثابت.
- **ليش إحنا:** العدّاد يوصل 05/05.
- **التواصل:** البوابة تفتح والنوع ينحدد مسبقاً. التحقق من الحقول والتركيز على أول خطأ يشتغلون. بدون بريد استقبال ما يدّعي النموذج الإرسال وما فيه mailto. مع بريد مضبوط ينبني رابط mailto صحيح.
- **الخاتمة:** تشتغل تلقائياً عند نهاية الصفحة مرة وحدة بس، والخطوات بالترتيب. التركيز يروح للخيار الأول، وEsc يطلع منها. «أعد المشهد» و«تخطَّ» يشتغلون. الخيارات الثلاثة كل واحد يسوي اللي مكتوب عليه، والنموذج المصغّر يتلعب بـ3 جولات ويتسكّر.
- **الإعدادات:** تقليل الحركة، والدليل، وإعادة المقدمة.
- **حالات خاصة:** وضع تقليل الحركة في النظام. الجوال 375px: بدون تمرير أفقي في أي مشهد، واللمس يشتغل، والقائمة تشتغل، وكل الأزرار ≥ 40px. التابلت 820px. وبدون JavaScript المحتوى يظهر كامل.
- **الجلسة الكاملة:** صفر أخطاء console، وصفر طلبات فاشلة، وصفر وحدات متعطلة.

## قيود معروفة
- الاختبارات تنفيذية على Chromium بس. Safari وFirefox ما اختبرتها بشكل فعلي.
- الصوت ما انسمع فعلياً لأن المتصفح headless. اللي تحقق منه الاختبار إن المؤشرات انطلقت وإن البديل يشتغل.
- القياس على الجوال كان محاكاة لمقاس الشاشة واللمس، مو جهاز حقيقي.
- `<dialog>` يحتاج متصفح حديث (2022 وما بعد). في المتصفحات القديمة الخاتمة ما تفتح، بس زر «أعد المشهد» يظهر والصفحة تكمل شغلها.
