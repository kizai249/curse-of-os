# «نقطة · NUQTA» — USERS-X guide avatar spec

Original character made for this experience. It is a proposal: the name and look need USERS-X approval.

## Concept
- **Name:** نقطة (Nuqta, "point"), from the brand line «كل لاعب هو نقطة التقاطع».
- **Role:** host and guide. Speaks only when greeted, clicked, when a game opens, at the contact portal and in the outro. It never interrupts on a timer.
- **Personality:** curious, confident, a bit mysterious. Short Saudi dialect lines.

## Silhouette (27 × 33 pixel grid, symmetric around x = 12.5)
| Part | Description |
|---|---|
| Head | Square Bone helmet. Its top corners have the dark D-pad arrow notches from the logo. |
| Visor | Void-black band. Two 2×2 Signal Cyan eyes that move one pixel at a time. |
| Mouth | 3×1 Pulse Magenta bar, or 3×2 while talking (the "player square"). |
| Antenna | Cyan four-point pixel sparkle on a shade stem (the brand's لمعة البكسل). |
| Body | Black streetwear hoodie with Bone drawstrings and magenta tips, from Merch Drop 01. |
| Core | 3×3 magenta square on the chest. It is the visitor, «إنت». |
| Edge | 1px Void line, a 2px Bone die-cut sticker edge, then the magenta step and cyan edge (العمق المجسّم). |

## Colours (the original palette only)
Bone `#F4F4F1` · Void `#0B0B0F` · Signal Cyan `#00DEE6` · Pulse Magenta `#F54BF7`, plus the neutrals shade `#33354C`, hood `#1B1C25` and hood2 `#2B2C3A`.

## Materials
Hard pixels with no anti-aliasing (`shape-rendering: crispEdges`), flat fills, and no chrome or glow, per the brand guidelines.

## Animation states (all in steps, never smooth tweens)
| State | Implementation |
|---|---|
| Idle | Head bobs by 1px (2.4s loop). The core dims for a moment every 3.2s. Random blink every 2.6–5.4s. |
| Look | Eyes shift −1/0/+1 px toward the pointer, quantised to a 3×3 grid and rAF-throttled. Only runs while the avatar is on screen. |
| Greet / wave | Swaps the right arm for the raised-arm pose and moves it 1px, 6 frames. |
| React (click) | 8px hop in 3 steps plus a blink. |
| Speak | The bubble text types out while the mouth swaps between frames. Screen readers get the full line at once through a live region. |
| Outro | Faces the viewer (eyes centred), says «اللعبة بدأت.», then waves when the choices appear. |
| Reduced motion | No bob, no hop and no typing. Lines appear at once. |

## Source & replacement
- Source of truth: `assets/avatar/nuqta.js` (pixel rectangles plus the SVG renderer).
- Static export: `assets/avatar/nuqta.svg`, generated by `node tools/export-assets.mjs`.
- The rig controller is the `Avatar` class in `script.js`. A GLB/GLTF version only needs a renderer that implements the same methods: `look(dx, dy)`, `lookAt(x, y)`, `blink()`, `react()`, `wave()`, `talk(text, bubble, sr)`, `set(attr, value)` and `destroy()`. The rest of the site calls only these.

## 3D production notes
- Keep the proportions: the head is about 9/33 of the height and the body is boxy. Build it voxel-style so the pixel identity survives in 3D.
- Rig: head (yaw/pitch, max 10° because the brand forbids rotating the symbol 45°), eyes as separate meshes or a texture offset, right arm with a wave clip, and a chest core with an emissive pulse (emission only, no bloom glow).
- Clips: `idle`, `blink`, `wave`, `hop`, `talk` (mouth swap), `face-viewer`.
- Budget: under 5k triangles and one 512² texture atlas. Ship a glTF binary (`.glb`) under 300 KB with Draco compression, and keep the SVG as the fallback when WebGL is missing.
