# عرض يوزرز إكس للشركاء

عرض تفاعلي للجهات والشركاء: 12 مشهد، يقدّمه «نقطة» بصوت وتعليقات ساخرة باللهجة السعودية، وفيه خمس ألعاب صغيرة:

| المشهد | اللعبة |
|---|---|
| المشكلة | صيد الانتباه: رجّع اللي يطالعون جوالاتهم للفعالية |
| غرفة الاختيار | بابين، ثلاث جولات، 10 ثواني لكل قرار |
| آخر من يصمد | اضغط وثبّت لين تكون آخر واحد |
| لعنة أوس | فك الشيفرة قبل ما تنطفي الشمعة |
| مشوار آسيا | ثلاث ضربات جزاء |

## التشغيل
افتح `index.html` من أي سيرفر ملفات ثابتة (مثلاً `python3 -m http.server`). الخطوط من Google Fonts.

## الصوت
- **صوت نقطة (الافتراضي):** 51 جملة مسجّلة بصوت بشري (ElevenLabs، صوت Callum) في `assets/voice/NN.mp3`، ونصوصها بنفس الترتيب في `assets/voice/lines.json`. فم نقطة يتحرك مع ارتفاع الصوت الحقيقي.
- **رطانة نقطة:** نغمات بكسل مع الترجمة المكتوبة. هذي هي الاحتياط لو ملف صوت ما اشتغل.
- **مكتوم:** الترجمة المكتوبة بس.
- زر «صوت» في الأعلى يبدّل بين الأوضاع.
- أي جملة جديدة تنضاف للعرض لازم تتسجّل وتنضاف لـ `VOICE_LINES` بنفس الترتيب، وإلا بتشتغل بالرطانة.
